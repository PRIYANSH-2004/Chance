# SORRY — a story of second chances

A ~48 s animation told entirely in glowing binary digits: realistic profile figures (tapered limbs,
IK walk cycle, hair, dress, jacket) sampled onto a fine grid of 0/1 characters, with falling
binary rain, wet-floor reflections, speech bubbles and chapter captions.

Open `index.html` in Chrome/Edge — it plays automatically (click once anywhere to unmute — browsers block autoplay sound).


- **Replay** restarts.
- `index.html?t=14.5` freezes on one frame (handy for tuning).
- Timeline: `scene()`; chapters: `CHAPTERS`; key beats: `T_SHATTER`, `T_HEART`.
